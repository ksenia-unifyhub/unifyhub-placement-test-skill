# Worked example

An invented interview (no real person): a QA engineer at a fintech company, tested with a QA & Testing profile.

- `transcript.txt`: the verbatim transcript, one speaker label per turn.
- `facts.json`: the teacher's facts (level B1+, ceiling found at B2).
- `report.json`: the draft report written with this skill, before the teacher's edits.

Check it yourself:

```bash
python3 ../scripts/check_quotes.py report.json transcript.txt
```
